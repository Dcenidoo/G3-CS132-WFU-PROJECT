# **Repository Navigation Guide**

## 1. **Folders**
Data Set
-
Data on Philippine higher education from 2019 and 2024 was collected to address the research questions and initial hypotheses of the project. The data set folder contains all of the data used in this study. 

The "WFU-Group-3-Data-Set" is the overall dataset master file, containing all higher education data used in the study. A PDF version and a .xlsx version is available in the repository for viewing.

The remaining files are subsets of data derived from the the original data masterfile.

"Budget" contains data on regional higher education budget allocations for 2019 and 2024.

"Enrollment" contains data on regional higher education enrollment statistics for 2019 and 2024.

"Enrollment-Budget-Merged" contains compile data data for regional higher education budget allocations, enrollment, and faculty-student ratios.
